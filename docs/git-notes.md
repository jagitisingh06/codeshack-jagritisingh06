\# Git Notes



Git is a version control system that helps developers track changes, maintain project history, and collaborate on software projects.



\## 1. git init



Initialises a new Git repository.

Example: `git init`



\## 2. git clone



Copies a remote repository to your computer.

Example: `git clone REPOSITORY\_URL`



\## 3. git status



Shows the current state of the working directory.

Example: `git status`



\## 4. git add



Stages changes for the next commit.

Example: `git add README.md`



\## 5. git commit



Records staged changes in the repository history.

Example: `git commit -m "Add project introduction"`



\## 6. git log



Displays previous commits.

Example: `git log --oneline`



\## 7. git diff



Shows changes that have not been staged.

Example: `git diff`



\## 8. git push



Uploads local commits to a remote repository.

Example: `git push origin main`



\## 9. git pull



Downloads and integrates changes from a remote branch.

Example: `git pull origin main`



\## 10. git fetch



Downloads remote updates without integrating them.

Example: `git fetch origin`



\## 11. git branch



Lists the available branches.

Example: `git branch`



\## 12. git switch



Switches to another branch or creates one.

Example: `git switch -c feature/notes`



\## 13. git remote -v



Displays remote repository URLs.

Example: `git remote -v`



\## 14. git merge



Integrates changes from another branch.

Example: `git merge feature/notes`



\## 15. git show



Displays information about a commit.

Example: `git show HEAD`
